# Graffiticode APP

## Local development

1. Run Graffiticode App in terminal

    ```bash
    # In the Graffiticode App root directory
    npm run dev
    ```

1. Run Graffiticode API and auth servers by following the instructions here (https://github.com/graffiticode/graffiticode)
